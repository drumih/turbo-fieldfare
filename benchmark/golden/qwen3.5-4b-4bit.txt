A mutex (mutual exclusion) is a synchronization primitive that allows only one thread to access a shared resource at a time. It is used to prevent race conditions when multiple threads try to access a shared resource simultaneously. You would use a mutex when you need to ensure that only one thread can execute a critical section of code at a time, such as when accessing a shared data structure or performing a complex operation that could be affected by concurrent access.
