# Fence syntax

Write ```bash``` when you mean the fence syntax inline; CommonMark reads it as a code span, because a backtick fence's info string may not contain a backtick.

A mid-line ``` in a sentence used to send the whole answer to raw text, headings and tables included.

| Marker | Meaning |
| --- | --- |
| Backtick fence | code block |
| Backtick span | inline code |
