### Build order

1. Configure the toolchain
    - Install Xcode 26
    - Select the toolchain
        - `xcode-select --switch`
        - Verify with `swift --version`
2. Build the package
    1. `swift build`
    2. `swift build --build-tests`
3. Run the focused filters

*   Three-space marker level one
    *   Four-space nested level two
        *   Level three
